OPTION 1: UPLOAD USING GIT (RECOMMENDED)
-----------------------------------------

1. Open Command Prompt or PowerShell in this folder

2. Initialize Git (if not already done):
   git init

3. Add all files:
   git add .

4. Check what will be committed:
   git status
   
   (You should NOT see: .env, node_modules, database.sqlite, dist/)

5. Commit:
   git commit -m "Initial commit: KAIROS Event Planning System"

6. Create a new repository on GitHub:
   - Go to: https://github.com/new
   - Name: kairos (or your preferred name)
   - Don't initialize with README (we already have one)
   - Click "Create repository"

7. Link and push:
   git remote add origin https://github.com/YOUR_USERNAME/kairos.git
   git branch -M main
   git push -u origin main

DONE! Your code is now on GitHub! 🎉

   - Drag and drop your ZIP file
