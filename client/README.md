# KAIROS Frontend

React + Vite client for KAIROS.

## Run

```bash
npm install
npm run dev
```

The frontend runs on `http://localhost:5173` and proxies API calls to `http://localhost:5000`.

## Build

```bash
npm run build
```

## Main Views

- Landing page
- Authentication page
- Event creation page
- Recommendations page (top 3)
- Booking history page
- Admin dashboard and management panels
